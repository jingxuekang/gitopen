# 快速启动指南

## 🎯 目标

让你在 30 分钟内看到小程序运行效果。

---

## 📋 前置要求

1. 已注册微信小程序账号（个人或企业）
2. 已安装微信开发者工具
3. 已获取小程序 AppID

如果还没有，请先访问 [微信公众平台](https://mp.weixin.qq.com/) 注册。

---

## 🚀 5 步快速启动

### 第 1 步：配置 AppID（2 分钟）

打开 `project.config.json` 文件，修改第 38 行：

```json
"appid": "wxYOUR_APPID_HERE"
```

将 `wxYOUR_APPID_HERE` 替换为你的小程序 AppID。

---

### 第 2 步：开通云开发（5 分钟）

1. 用微信开发者工具打开本项目
2. 点击工具栏的"云开发"按钮
3. 按提示开通云开发（免费版即可）
4. 创建一个云环境，记下环境 ID（格式如：`cloud1-xxx`）

---

### 第 3 步：配置云环境 ID（1 分钟）

打开 `miniprogram/app.js` 文件，修改第 8 行：

```javascript
env: 'cloud1-xxx'  // 替换为你的云环境 ID
```

---

### 第 4 步：创建数据库集合（5 分钟）

在微信开发者工具中：

1. 点击"云开发"按钮
2. 进入"数据库"标签
3. 点击"添加集合"，创建以下集合：

```
✓ users              (用户信息)
✓ products           (商品信息)
✓ cart_items         (购物车)
✓ orders             (订单)
✓ addresses          (收货地址)
✓ reviews            (评价)
✓ coupons            (优惠券)
✓ user_coupons       (用户优惠券)
✓ group_activities   (拼团活动)
✓ groups             (拼团记录)
```

**权限设置**：每个集合都选择"仅创建者可读写"（开发阶段）

---

### 第 5 步：部署云函数（10 分钟）

在微信开发者工具的左侧文件树中：

1. 展开 `cloudfunctions` 目录
2. 右键点击每个云函数文件夹
3. 选择"上传并部署：云端安装依赖"

**必须部署的核心云函数**（至少这 10 个）：
```
✓ login              (用户登录)
✓ getUserProfile     (获取用户信息)
✓ getProducts        (获取商品列表)
✓ getProductDetail   (获取商品详情)
✓ getCart            (获取购物车)
✓ addToCart          (添加到购物车)
✓ updateCartItem     (更新购物车)
✓ deleteCartItem     (删除购物车商品)
✓ createOrder        (创建订单)
✓ getOrders          (获取订单列表)
```

**建议**：全部部署（36 个云函数），避免后续功能报错。

## 🎨 临时解决 TabBar 图标问题

小程序需要 TabBar 图标才能启动。有两个快速方案：

### 方案 A：临时注释 TabBar（最快）

打开 `miniprogram/app.json`，注释掉 tabBar 配置：

```json
{
  "pages": [...],
  "window": {...}
  // 临时注释掉，等有图标后再启用
  // "tabBar": {
  //   "color": "#999999",
  //   ...
  // }
}
```

**缺点**：没有底部导航栏，需要手动输入页面路径测试。

### 方案 B：快速创建占位图标（推荐）

1. 访问 [iconfont.cn](https://www.iconfont.cn/)
2. 搜索并下载以下图标（PNG 格式，81x81）：
   - home（首页）
   - category（分类）
   - cart（购物车）
   - user（用户）
3. 每个图标下载两个颜色版本：
   - 灰色版本（未选中）
   - 绿色版本（选中）
4. 重命名并放入 `miniprogram/images/tab/` 目录：
   ```
   home.png
   home-active.png
   category.png
   category-active.png
   cart.png
   cart-active.png
   user.png
   user-active.png
   ```

## 📦 添加测试数据（5 分钟）

### 方法 1：使用云开发控制台手动添加

在云开发控制台 → 数据库 → products 集合中，点击"添加记录"：

```json

  "name": "西湖龙井",
  "category": "tea",
  "images": ["https://via.placeholder.com/400"],
  "description": "正宗西湖龙井，清香甘醇",
  "price": 29800,
  "originalPrice": 39800,
  "stock": 100,
  "sales": 0,
  "rating": 5.0,
  "reviewCount": 0,
  "status": 1,
  "createdAt": "2024-01-01T00:00:00.000Z",
  "updatedAt": "2024-01-01T00:00:00.000Z"
```

部署 `database-init` 云函数后，在云开发控制台运行它，会自动创建测试数据。

## 🐛 常见问题

### Q1: 编译报错 "tabBar 图标不存在"
**解决**：使用方案 A 临时注释 TabBar，或使用方案 B 创建图标

### Q2: 点击按钮没反应，控制台报错 "cloud function not found"
**解决**：检查对应的云函数是否已部署

### Q3: 商品列表为空
**解决**：需要在数据库中添加商品数据

### Q4: 登录失败
**解决**：检查云环境 ID 是否正确配置

### Q5: 真机预览白屏
**解决**：
1. 检查 AppID 是否正确
2. 在微信公众平台添加开发者账号
3. 检查云函数是否全部部署成功
