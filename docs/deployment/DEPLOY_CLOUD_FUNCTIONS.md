# 云函数部署指南

## 当前问题
错误信息：`FUNCTION_NOT_FOUND` - 云函数未找到

这是因为云函数代码在本地，但还没有上传到云端。

## 需要部署的核心云函数

### 用户相关（必须）
1. **login** - 用户登录
2. **getUserInfo** - 获取用户信息  
3. **updateUserInfo** - 更新用户信息（头像、昵称）

### 首页相关（必须）
4. **getHomeData** - 获取首页数据（轮播图、推荐商品等）

### 商品相关（必须）
5. **getProducts** - 获取商品列表
6. **getProductDetail** - 获取商品详情

### 购物车相关（可选）
7. **getCart** - 获取购物车
8. **addToCart** - 添加到购物车

### 订单相关（可选）
9. **getOrders** - 获取订单列表
10. **createOrder** - 创建订单

## 部署步骤

### 方法1：逐个部署（推荐新手）

1. 在微信开发者工具中，找到左侧"云开发"图标
2. 点击"云函数"目录
3. 右键点击 `cloudfunctions/login` 文件夹
4. 选择"上传并部署：云端安装依赖"
5. 等待上传完成（会显示绿色对勾✓）
6. 重复步骤3-5，依次部署以下云函数：
   - login
   - getUserInfo
   - updateUserInfo
   - getHomeData
   - getProducts
   - getProductDetail

### 方法2：批量部署（推荐熟练用户）

1. 右键点击 `cloudfunctions` 文件夹
2. 选择"同步云函数列表"
3. 然后右键每个云函数文件夹
4. 选择"上传并部署：云端安装依赖"

## 常见问题

### Q1: 上传失败
**原因**：
- 网络问题
- 云环境未初始化
- 没有权限

**解决**：
1. 检查网络连接
2. 确认已创建云环境（cloud1-0gswdm2a347e7be7）
3. 确认使用真实 AppID（wxaa48431da9ffdad2）

### Q2: 部署后仍然报错
**原因**：
- 云函数代码有错误
- 数据库集合不存在
- 权限配置问题

**解决**：
1. 查看云函数日志
2. 创建必要的数据库集合（users, products, orders等）
3. 检查云函数权限配置

### Q3: 依赖安装失败
**原因**：
- package.json 配置错误
- npm 源问题

**解决**：
1. 检查 package.json 文件
2. 使用"云端安装依赖"而不是"本地安装依赖"
