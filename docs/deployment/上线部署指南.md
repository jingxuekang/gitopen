## 三、云函数部署步骤

### 方法1：批量部署（推荐）
1. 在微信开发者工具中，右键点击 `cloudfunctions` 文件夹
2. 选择"同步云函数列表"
3. 逐个右键每个云函数文件夹
4. 选择"上传并部署：云端安装依赖"
5. 等待部署完成（每个约1-2分钟）

### 方法2：云端控制台部署
1. 打开微信开发者工具 → 云开发控制台
2. 点击"云函数"标签
3. 点击"新建云函数"或选择已有函数
4. 在线编辑代码或上传代码包
5. 点击"保存并部署"

### 注意事项
- 确保每个云函数的 `package.json` 包含 `wx-server-sdk` 依赖
- 部署时选择"云端安装依赖"，不要选择"不安装依赖"
- 部署完成后在控制台测试云函数是否正常

## 四、数据库初始化

### 1. 创建数据库集合
在云开发控制台 → 数据库，创建以下集合：

```
users          - 用户信息
products       - 商品信息
orders         - 订单信息
carts          - 购物车
addresses      - 收货地址
coupons        - 优惠券
reviews        - 商品评价
categories     - 商品分类
```

### 2. 导入商品数据
1. 打开 `sample-products.json` 文件
2. 在云开发控制台 → 数据库 → products 集合
3. 点击"导入" → 选择 JSON 文件
4. 确认导入成功（应该有10条商品数据）

### 3. 设置数据库权限
在每个集合的"权限设置"中：
- users: 仅创建者可读写
- products: 所有用户可读，仅管理员可写
- orders: 仅创建者可读写
- carts: 仅创建者可读写
- addresses: 仅创建者可读写
- coupons: 所有用户可读，仅管理员可写
- reviews: 所有用户可读，仅创建者可写

## 十、常见问题

### 1. 云函数调用失败
- 检查云函数是否部署成功
- 检查云函数权限配置
- 查看云函数日志排查错误

### 2. 图片无法显示
- 检查图片URL是否有效
- 检查域名是否已配置
- 检查云存储权限

### 3. 数据库操作失败
- 检查数据库权限设置
- 检查集合是否存在
- 查看云函数日志

### 4. 支付失败
- 检查商户号配置
- 检查证书文件
- 查看支付日志

## 十一、版本更新流程

1. 在本地开发新功能

1. 点击"上传"

3. 填写更新说明

### 3. 提交审核
1. 在微信公众平台提交审核
2. 等待审核通过（约1-7天）

### 4. 发布上线
1. 审核通过后点击"发布"
2. 用户将在24小时内收到更新
