## 📋 下一步操作

### 步骤 1：部署云函数

在微信开发者工具中：

1. **设置云环境**
   - 右键点击 `cloudfunctions` 文件夹
   - 选择"当前环境" → `cloud1`
   - 确认环境已切换

2. **部署核心云函数**（按顺序部署）

   依次右键点击以下文件夹，选择"上传并部署：云端安装依赖"：

   **必须部署**：
   - ✅ `getHomeData` - 首页数据
   - ✅ `getProducts` - 商品列表
   - ✅ `getProductDetail` - 商品详情
   - ✅ `getUserProfile` - 用户信息
   
   **可选部署**（后续需要时再部署）：
   - `getCart` - 购物车
   - `addToCart` - 添加购物车
   - `getOrders` - 订单列表
   - `createOrder` - 创建订单
   - `getAddresses` - 地址列表
   - `addAddress` - 添加地址

3. **等待部署完成**
   - 每个云函数部署需要 30秒-2分钟
   - 底部会显示部署进度
   - 看到"上传成功"即可

### 步骤 2：初始化数据库

1. **打开云开发控制台**
   - 点击顶部"云开发"按钮
   - 或访问：https://console.cloud.tencent.com/tcb

2. **创建数据库集合**
   
   点击"数据库" → "添加集合"，创建以下集合：

   **必须创建**：
   - `products` - 商品表
   - `users` - 用户表
   - `categories` - 分类表（可选）

   **可选创建**：
   - `carts` - 购物车
   - `orders` - 订单
   - `addresses` - 地址
   - `coupons` - 优惠券
   - `reviews` - 评价

3. **设置数据库权限**
   
   对每个集合：
   - 点击集合名称
   - 点击"权限设置"
   - 选择"所有用户可读，仅创建者可写"

### 步骤 4：上传图片资源

1. **打开云存储**
   - 云开发控制台 → 存储

2. **创建文件夹**
   - 点击"新建文件夹"
   - 创建 `products` 文件夹

3. **上传商品图片**
   - 进入 `products` 文件夹
   - 点击"上传文件"
   - 选择商品图片上传

4. **获取图片 URL**
   - 上传后，点击图片
   - 复制"文件 ID"（格式：`cloud://xxx.jpg`）
   - 将这个 ID 填入商品数据的 `image` 字段

### 步骤 5：测试

1. **重新编译小程序**
   - 点击"编译"按钮

2. **查看首页**

     - 云函数是否部署成功
     - 数据库中是否有数据
     - 控制台是否有错误

3. **查看控制台**
   - 点击"调试器" → "Console"
   - 查看是否有错误信息

## ⚠️ 常见问题

### Q1: 云函数部署失败

**原因**：网络问题或依赖安装失败

**解决**：
1. 检查网络连接
2. 重试部署
3. 查看部署日志

### Q2: 首页没有数据

**原因**：数据库为空或云函数未部署

**解决**：
1. 检查数据库中是否有数据
2. 检查云函数是否部署成功
3. 查看控制台错误信息

### Q3: 图片不显示

**原因**：图片 URL 错误或未上传

**解决**：
1. 确认图片已上传到云存储
2. 使用正确的文件 ID（`cloud://xxx`）
3. 或使用 HTTPS 网络图片
