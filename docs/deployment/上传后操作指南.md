# 小程序上传后操作指南

## 一、登录微信公众平台

1. 访问：https://mp.weixin.qq.com
2. 使用管理员微信扫码登录
3. 进入小程序后台

---

## 二、提交审核

### 1. 进入开发管理
- 左侧菜单：开发 → 开发管理
- 找到"开发版本"区域
- 看到刚才上传的版本（版本号：1.0.0）

### 2. 选为体验版（可选）
- 点击"选为体验版"
- 体验版可以让团队成员先测试
- 扫码即可在手机上体验

### 3. 提交审核
点击"提交审核"按钮，填写以下信息：

#### 基本信息
- **小程序名称：** 茶叶商城（或你的实际名称）
- **简介：** 专注白茶、陈皮、紫砂壶的精品茶叶商城
- **标签：** 茶叶、白茶、陈皮、紫砂壶、商城

#### 服务类目
选择合适的类目（必须与营业执照一致）：
- **一级类目：** 商家自营
- **二级类目：** 食品
- **资质材料：** 上传食品经营许可证（如有）

或者：
- **一级类目：** 电商平台
- **二级类目：** 电商平台
- **资质材料：** 根据要求上传

#### 功能页面配置
需要配置至少2个功能页面：

**页面1：首页**
- 页面路径：`pages/index/index`
- 页面标题：首页
- 页面截图：上传首页截图
- 功能描述：浏览商品、查看排行榜、搜索商品

**页面2：商品分类**
- 页面路径：`pages/category/category`
- 页面标题：分类
- 页面截图：上传分类页截图
- 功能描述：按分类筛选商品、多级筛选

**页面3：购物车**
- 页面路径：`pages/cart/cart`
- 页面标题：购物车
- 页面截图：上传购物车截图
- 功能描述：管理购物车商品、结算

**页面4：个人中心**
- 页面路径：`pages/user/user`
- 页面标题：我的
- 页面截图：上传个人中心截图
- 功能描述：查看订单、管理地址、优惠券

#### 测试账号（如需要）
如果审核人员需要登录才能看到完整功能：
- 提供测试账号和密码
- 或说明"无需登录即可浏览"

#### 补充说明
```
本小程序为茶叶商城，主要销售白茶、陈皮、紫砂壶等茶文化相关商品。
用户可以浏览商品、加入购物车、下单购买。
支持会员等级、优惠券等营销功能。
```

### 4. 确认提交
- 仔细检查所有信息
- 勾选"我已阅读并同意《微信小程序平台服务条款》"
- 点击"提交审核"

---

## 三、等待审核

### 审核时间
- 一般：1-7个工作日
- 快的话：当天或次日
- 节假日会延长

### 审核状态查看
- 开发管理 → 审核版本
- 可以看到审核进度

### 可能的审核结果

#### 1. 审核通过 ✅
- 会收到微信通知
- 可以点击"发布"上线

#### 2. 审核不通过 ❌
常见原因：
- 类目资质不符
- 功能描述不清晰
- 页面截图不完整
- 缺少必要的用户协议/隐私政策
- 商品信息不完整

**解决方案：**
- 查看驳回原因
- 根据要求修改
- 重新提交审核

---

## 四、发布上线

### 审核通过后
1. 进入"审核版本"
2. 点击"发布"按钮
3. 确认发布

### 发布后
- 用户可以在微信搜索到你的小程序
- 可以通过小程序码分享
- 24小时内全量生效

## 五、版本管理

### 线上版本
- 当前正式运行的版本
- 用户访问的就是这个版本

### 体验版本
- 供内部测试使用
- 需要添加体验成员才能访问

### 开发版本
- 刚上传的版本
- 只有开发者可以看到

- 下载小程序码

### 3. 附近的小程序
路径：推广 → 附近的小程序
- 添加门店地址
- 用户可以在"附近的小程序"中找到

### 4. 搜索优化
- 完善小程序名称和介绍
- 添加准确的服务标签
- 提高用户活跃度

## 八、数据分析

### 1. 实时统计
路径：统计 → 实时统计
- 实时访问人数
- 实时分享次数

### 2. 数据分析
路径：统计 → 数据分析
- **访问分析：** UV、PV、访问时长、访问深度
- **来源分析：** 用户从哪里进入
- **用户画像：** 性别、年龄、地域分布
- **页面分析：** 各页面访问情况

### 3. 自定义分析
路径：统计 → 自定义分析
- 可以创建自定义事件
- 分析特定功能的使用情况

## 九、支付功能开通（如需要）

### 1. 申请微信支付
路径：功能 → 微信支付
- 点击"开通"
- 填写商户信息
- 提交资料
- 等待审核（1-3个工作日）

### 2. 获取支付参数
审核通过后：
- 商户号（mchid）
- API密钥（key）
- 下载证书文件

### 3. 配置到云函数
在 `createPayment` 云函数中配置：
```javascript
const mchid = '你的商户号'
const key = '你的API密钥'
```

## 十、常见问题

### 1. 审核被拒怎么办？
- 仔细阅读驳回原因
- 根据要求修改代码或资料
- 重新上传并提交审核

### 2. 如何加急审核？
- 微信小程序不支持加急审核
- 只能等待正常审核流程

### 3. 可以修改已发布的版本吗？
- 不能直接修改
- 需要上传新版本，重新审核发布

### 4. 如何回滚到旧版本？
- 开发管理 → 历史版本
- 选择要回滚的版本
- 点击"回退"

### 5. 体验版和正式版有什么区别？
- 体验版：内部测试，需要添加体验成员
- 正式版：所有用户可访问

## 十一、版本更新流程

### 1. 开发新功能
- 在本地开发新功能
- 充分测试

### 2. 上传新版本
- 修改版本号（如 1.0.0 → 1.1.0）
- 点击"上传"
- 填写更新说明

### 3. 提交审核
- 说明本次更新内容
- 提交审核

### 4. 发布
- 审核通过后发布
- 用户会在24小时内收到更新
