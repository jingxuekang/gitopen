## ⚠️ 需要配置的项目（5%）

### 1. 必须配置 ⚠️

#### 1.1 小程序 AppID
- **文件**: `project.config.json`
- **位置**: 第 38 行
- **操作**: 替换 `"your-appid"` 为你的小程序 AppID
- **获取方式**: 在微信公众平台注册小程序

#### 1.2 云环境 ID
- **文件**: `miniprogram/app.js`
- **位置**: 第 8 行
- **操作**: 替换 `"your-env-id"` 为你的云环境 ID
- **获取方式**: 在微信开发者工具中开通云开发

#### 1.3 TabBar 图标
- **目录**: `miniprogram/images/tab/`
- **需要**: 8 个图标文件（home, category, cart, user 各两个状态）
- **规格**: 81x81 像素 PNG 格式
- **临时方案**: 可以先注释掉 app.json 中的 tabBar 配置

#### 1.4 数据库集合
- **操作**: 在云开发控制台创建 10 个数据库集合
- **集合**: users, products, cart_items, orders, addresses, reviews, coupons, user_coupons, group_activities, groups

#### 1.5 云函数部署
- **操作**: 上传并部署 36 个云函数
- **方式**: 在微信开发者工具中右键云函数文件夹 → 上传并部署

### 2. 可选配置（后续完善）

#### 2.1 微信支付
- **需要**: 申请微信支付商户号
- **配置**: 在 createPayment 云函数中配置支付参数
- **说明**: 开发阶段可以跳过，不影响其他功能测试

#### 2.2 商品数据
- **操作**: 在数据库中添加商品数据
- **方式**: 手动添加或运行 database-init 云函数
- **说明**: 至少添加 3-5 个商品才能看到效果

#### 2.3 定时触发器
- **云函数**: checkExpiredOrders, checkExpiredGroups
- **配置**: 在云开发控制台配置定时触发器
- **说明**: 用于自动处理过期订单和拼团

#### 2.4 物流 API
- **需要**: 申请第三方物流查询 API
- **配置**: 在 getLogistics 云函数中配置
- **说明**: 可以先使用模拟数据
