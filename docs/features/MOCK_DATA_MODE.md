## 如何使用

### 当前状态（模拟数据模式）

1. 打开微信开发者工具
2. 点击"编译"按钮
3. 小程序会使用模拟数据运行
4. 可以测试所有页面布局和交互

### 切换到云服务模式

当你准备好使用云服务时：

1. **配置云开发环境**
   ```javascript
   // miniprogram/app.js
   // 取消注释并替换环境 ID
   wx.cloud.init({
     env: 'your-cloud-env-id',
     traceUser: true,
   })
   ```

2. **关闭模拟数据**
   ```javascript
   // miniprogram/utils/api.js
   const USE_MOCK_DATA = false  // 改为 false
   ```

3. **部署云函数**
   - 在微信开发者工具中右键每个云函数
   - 选择"上传并部署：云端安装依赖"

4. **初始化数据库**
   - 运行 `database-init` 云函数
   - 导入商品数据

## 常见问题

### Q: 为什么有些图片不显示？

A: 模拟数据中的图片路径是示例路径，实际文件可能不存在。这不影响功能测试。

### Q: 点击商品没有反应？

A: 商品详情页需要完整的商品数据。可以在模拟数据中添加更多字段。

### Q: 如何测试筛选功能？

A: 在分类页选择不同的筛选条件，模拟数据会根据条件过滤商品。

### Q: 购物车为什么是空的？

A: 模拟数据中购物车默认为空。可以在 `mockData.js` 中添加购物车数据。

## 技术说明

### 模拟数据实现原理

```javascript
// api.js 中的判断
if (USE_MOCK_DATA) {
  // 使用 mockData.js 中的数据
  return mockApi[name](data)
} else {
  // 调用真实的云函数
  return wx.cloud.callFunction({ name, data })
}
```

### 优势

1. **无需云服务**：开发阶段不需要配置云环境
2. **快速测试**：立即看到效果，无需等待网络请求
3. **离线开发**：没有网络也能开发
4. **成本节约**：开发阶段不产生云服务费用

### 限制

1. **数据固定**：模拟数据是写死的，不会变化
2. **功能受限**：无法测试真实的数据库操作
3. **不支持登录**：无法测试用户相关功能
