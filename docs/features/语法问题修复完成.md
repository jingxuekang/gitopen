## 修复模式总结

### 价格格式化通用模式

**在 JS 文件中：**
```javascript
// 单个价格
const formattedPrice = (price / 100).toFixed(2)

// 数组数据
const formattedItems = items.map(item => ({
  ...item,
  formattedPrice: (item.price / 100).toFixed(2)
}))

// 对象数据
this.setData({
  order: {
    ...orderData,
    formattedTotalAmount: (orderData.totalAmount / 100).toFixed(2),
    items: orderData.items.map(item => ({
      ...item,
      formattedPrice: (item.price / 100).toFixed(2)
    }))
  }
})
```

**在 WXML 文件中：**
```xml
<!-- 直接使用格式化后的字段 -->
<text>¥{{formattedPrice}}</text>
<text>¥{{item.formattedPrice}}</text>
<text>¥{{order.formattedTotalAmount}}</text>
```

## 注意事项

1. **价格单位：** 所有价格在数据库中以"分"为单位存储，显示时需要除以100
2. **格式化时机：** 在数据加载后立即格式化，避免在 WXML 中进行计算
3. **命名规范：** 格式化字段使用 `formatted` 前缀或 `Text` 后缀
4. **性能考虑：** 格式化操作在数据加载时一次性完成，不影响渲染性能
