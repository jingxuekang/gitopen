# 登录和头像功能使用指南

## 功能说明

### 1. 登录功能
- 点击"点击登录"按钮即可登录
- 使用微信授权登录，无需输入账号密码
- 登录后自动创建用户账号
- 支持自动登录（保存登录状态）

### 2. 头像修改
- 登录后，点击头像可以选择新头像
- 支持从相册选择或拍照
- 头像自动上传到云存储
- 按住头像会显示"点击修改"提示

### 3. 昵称修改
- 点击昵称输入框可以修改昵称
- 输入完成后失去焦点自动保存
- 昵称不能为空

## 部署步骤

### 1. 部署云函数

需要部署以下云函数：

#### login（登录）
```bash
右键 cloudfunctions/login → 上传并部署：云端安装依赖
```

#### updateUserInfo（更新用户信息）
```bash
右键 cloudfunctions/updateUserInfo → 上传并部署：云端安装依赖
```

### 2. 创建数据库集合

在云开发控制台创建 `users` 集合，字段结构：
```json
{
  "_id": "自动生成",
  "openid": "用户openid",
  "unionid": "用户unionid（可选）",
  "nickname": "用户昵称",
  "avatar": "头像云存储fileID",
  "phone": "手机号",
  "memberLevel": 0,
  "totalSpent": 0,
  "createdAt": "创建时间",
  "updatedAt": "更新时间"
}
```

### 3. 配置云存储权限

在云开发控制台 → 云存储 → 权限设置：
- 允许所有用户读取
- 允许所有用户写入（或仅允许登录用户写入）

## 测试步骤

### 测试登录
1. 打开小程序，进入"我的"页面
2. 点击"点击登录"按钮
3. 查看是否显示用户信息
4. 检查控制台是否有错误

### 测试头像修改
1. 登录后，点击头像
2. 选择一张图片
3. 等待上传完成
4. 查看头像是否更新

### 测试昵称修改
1. 登录后，点击昵称输入框
2. 输入新昵称
3. 点击其他地方（失去焦点）
4. 查看昵称是否更新

## 常见问题

### Q1: 点击登录没反应
**原因**: 
- 云函数未部署
- 网络问题
- AppID 配置错误

**解决**: 
1. 检查云函数是否部署成功
2. 查看控制台错误信息
3. 确认使用真实 AppID

### Q2: 头像上传失败
**原因**:
- 云存储权限未配置
- 图片过大
- 网络问题

**解决**:
1. 检查云存储权限设置
2. 选择较小的图片（建议 < 2MB）
3. 检查网络连接

### Q3: 昵称修改不生效
**原因**:
- updateUserInfo 云函数未部署
- 昵称为空
- 网络问题

**解决**:
1. 部署 updateUserInfo 云函数
2. 确保输入了昵称
3. 查看控制台错误信息

## 默认头像

当前使用 SVG base64 内联图片作为默认头像：
- 绿色背景（#2C5F2D）
- 白色用户图标
- 无需额外图片文件

如需更换默认头像：
1. 准备 200x200 的图片
2. 放到 `images/default-avatar.png`
3. 修改代码中的 `defaultAvatar` 路径

## 会员等级

登录后会显示会员等级：
- 普通会员：0 元
- 银卡会员：1000 元
- 金卡会员：5000 元

会员等级根据累计消费自动升级。
