## 设计系统应用

### 🎨 色彩方案
```css
/* 主色调 - 茶绿色系 */
#2C5F2D  /* 深茶绿 */
#4A7C4E  /* 中茶绿 */
#E8F5E9  /* 浅茶绿 */

/* 辅助色 */
#D4AF37  /* 会员金 */
#FF9800  /* 强调橙 */
#2196F3  /* 信息蓝 */
#4CAF50  /* 充值绿 */
#E74C3C  /* 价格红 */

/* 渐变效果 */
linear-gradient(135deg, #2C5F2D 0%, #4A7C4E 100%)
linear-gradient(135deg, #FFFFFF 0%, #F8F8F8 100%)
```

### 📐 圆角规范
```css
50rpx  /* 超大圆角 - 搜索栏、胶囊标签 */
44rpx  /* 大圆角 - 按钮 */
40rpx  /* 中大圆角 - 卡片底部 */
16rpx  /* 中圆角 - 商品卡片、功能卡片 */
12rpx  /* 小圆角 - 小元素 */
```

### 🌟 阴影系统
```css
/* 轻阴影 - 卡片 */
box-shadow: 0 4rpx 16rpx rgba(0, 0, 0, 0.06);

/* 中阴影 - 搜索栏、底部栏 */
box-shadow: 0 4rpx 20rpx rgba(0, 0, 0, 0.08);

/* 重阴影 - 悬浮效果 */
box-shadow: 0 8rpx 24rpx rgba(0, 0, 0, 0.12);

/* 彩色阴影 - 按钮 */
box-shadow: 0 8rpx 20rpx rgba(44, 95, 45, 0.3);
box-shadow: 0 8rpx 20rpx rgba(76, 175, 80, 0.3);
box-shadow: 0 8rpx 20rpx rgba(33, 150, 243, 0.3);
box-shadow: 0 8rpx 20rpx rgba(255, 152, 0, 0.3);
```

### ⚡ 动画效果
```css
/* 点击缩放 */
.element:active {
  transform: scale(0.95);
  transition: all 0.2s;
}

/* 悬浮上移 */
.element:active {
  transform: translateY(-4rpx);
  box-shadow: 0 8rpx 24rpx rgba(0, 0, 0, 0.12);
}

/* 筛选器缩放 */
.filter-option.active {
  transform: scale(1.05);
}
```

### ✨ 特效应用
```css
/* 毛玻璃效果 */
backdrop-filter: blur(20rpx);
background: rgba(255, 255, 255, 0.95);

/* 装饰元素 */
.element::before {
  content: '';
  position: absolute;
  background: radial-gradient(circle, rgba(255,255,255,0.1) 0%, transparent 70%);
}
```

## 技术亮点

### 1. 渐变背景
- 使用 135deg 角度统一视觉方向
- 多色渐变增加层次感
- 半透明渐变营造轻盈感

### 2. 毛玻璃效果
- `backdrop-filter: blur()` 实现背景模糊
- 配合半透明背景增强层次
- 适用于浮层、底部栏等元素

### 3. 点击反馈
- `transform: scale(0.95)` 缩放反馈
- `transform: translateY(-4rpx)` 上移反馈
- 配合阴影变化增强立体感

### 4. 装饰元素
- 使用 `::before` / `::after` 伪元素
- 径向渐变创建光晕效果
- 不增加 DOM 节点，性能更好

## 性能优化

### 1. CSS 动画
- 使用 `transform` 而非 `top/left`
- GPU 加速，性能更好
- 动画流畅不卡顿

### 2. 阴影优化
- 合理使用阴影数量
- 避免过度模糊
- 保持性能平衡

### 3. 渐变优化
- 使用 CSS 渐变而非图片
- 减少资源加载
- 适配不同屏幕
