## 📊 数据库字段对应

### 茶叶商品示例

```json
{
  "name": "福鼎白毫银针",
  "category": "tea",
  "filters": {
    "type": "yinzhen",  // 银针
    "age": "3"          // 三年
  }
}
```

### 陈皮商品示例

```json
{
  "name": "新会一线陈皮",
  "category": "chenpi",
  "filters": {
    "origin": "yixian",  // 一线产区
    "age": "10"          // 十年
  }
}
```

### 紫砂壶商品示例

```json
{
  "name": "子冶石瓢紫泥壶",
  "category": "teapot",
  "filters": {
    "shape": "ziyeshipiao",      // 子冶石瓢
    "material": "zini",           // 紫泥
    "craft": "full"               // 全手工
  }
}
```
