## 技术实现

### 核心技术
1. **CSS 渐变**
   - `linear-gradient(135deg, ...)`
   - `radial-gradient(circle, ...)`

2. **阴影系统**
   - 轻阴影：`0 4rpx 16rpx rgba(0, 0, 0, 0.06)`
   - 中阴影：`0 4rpx 20rpx rgba(0, 0, 0, 0.08)`
   - 重阴影：`0 8rpx 24rpx rgba(0, 0, 0, 0.12)`
   - 彩色阴影：`rgba(44, 95, 45, 0.3)` 等

3. **动画效果**
   - 点击缩放：`transform: scale(0.95)`
   - 悬浮上移：`transform: translateY(-4rpx)`
   - 选中缩放：`transform: scale(1.05)`

4. **特效应用**
   - 毛玻璃：`backdrop-filter: blur(20rpx)`
   - 装饰光晕：`::before` 伪元素 + 径向渐变
   - 半透明遮罩：`rgba()` 颜色

### 色彩方案
- **主色调：** 茶绿色系 (#2C5F2D, #4A7C4E, #E8F5E9)
- **辅助色：** 金色、橙色、蓝色、绿色、红色

### 圆角规范
- 50rpx (超大) - 搜索栏、胶囊
- 44rpx (大) - 按钮

- 16rpx (中) - 商品卡片

### 间距规范
- 60rpx (超大)
- 40rpx (大)
- 30rpx (中)
- 20rpx (小)
- 10rpx (超小)
