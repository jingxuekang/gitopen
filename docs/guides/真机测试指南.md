### 本地 vs 真机的区别
- **本地开发环境：** 可能有缓存的登录状态，显示完整功能
- **真机环境：** 全新环境，需要重新登录

### 为什么真机只显示"点击登录"？
这是正常的！因为：
1. 真机是全新环境，没有登录信息
2. `isLogin` 状态为 `false`
3. 所以显示未登录界面

**如果登录失败，解决方案：**

方案1：检查云函数部署
```bash

1. 右键 cloudfunctions/login 文件夹
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成
4. 在云开发控制台测试云函数
```

方案2：使用临时模拟登录（开发测试用）
- 修改 `pages/user/user.js` 中的 `onLogin` 方法
- 使用本地存储模拟登录状态
- 仅用于测试UI，不能用于生产环境

## 四、常见问题排查

### 问题1：首页没有商品显示
**原因：** 数据库中没有商品数据
**解决：** 导入商品数据到 products 集合

### 问题2：点击登录没反应
**原因：** 云函数未部署或部署失败
**解决：** 
1. 检查云函数部署状态
2. 查看控制台错误日志
3. 重新部署 login 云函数

### 问题3：登录后显示"测试用户"
**原因：** 使用了模拟登录
**解决：** 这是正常的，模拟登录会显示默认昵称

### 问题4：底部导航不显示
**原因：** 自定义TabBar组件未正确加载
**解决：** 
1. 检查 `app.json` 中的 `usingComponents` 配置
2. 确认 `custom-tabbar` 组件存在

### 问题5：图片不显示
**原因：** 
- 网络问题
- 图片URL无效
- 云存储权限问题

**解决：**
1. 检查网络连接
2. 使用有效的图片URL
3. 配置云存储权限为"所有用户可读"
