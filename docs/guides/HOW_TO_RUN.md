# 如何运行茶叶商城小程序

## 问题说明

如果遇到以下错误：
- `game.json 未找到` - 项目被识别为小游戏
- `logs.wxss Unknown word` - 缓存了其他项目的文件
- 文件乱码错误

## 解决方案

### 方法 1：清理并重新导入（推荐）

1. **完全关闭微信开发者工具**

2. **删除工具缓存**
   - Windows: `C:\Users\你的用户名\AppData\Local\微信开发者工具\User Data`
   - 或者在工具中：工具 → 清除缓存 → 清除全部缓存

3. **重新打开微信开发者工具**

4. **导入项目**
   - 点击"+"号
   - 项目目录：选择 `D:\workspace\weChatShop\miniprogram` 文件夹（注意是 miniprogram 子目录）
   - AppID：`wx954cd3a36add1944`
   - 项目名称：`茶叶商城`
   - 后端服务：选择"不使用云服务"

5. **编译运行**
   - 点击"编译"按钮
   - 应该能看到首页

### 方法 2：使用正确的项目配置

如果方法 1 不行，在 `miniprogram` 目录下创建独立的 `project.config.json`：

1. **进入 miniprogram 目录**
   ```
   cd D:\workspace\weChatShop\miniprogram
   ```

2. **创建配置文件**（我会帮你创建）

3. **用微信开发者工具打开 miniprogram 目录**

## 常见问题

### Q1: 显示"小游戏模式"

**原因**：导入了根目录而不是 miniprogram 目录

**解决**：
1. 关闭项目
2. 重新导入，选择 `D:\workspace\weChatShop\miniprogram` 目录

### Q2: 提示 game.json 未找到

**原因**：同上，项目被识别为小游戏

**解决**：导入 miniprogram 目录

### Q3: logs.wxss 文件乱码

**原因**：缓存了其他项目的文件

**解决**：
1. 工具 → 清除缓存 → 清除全部缓存
2. 重新编译

### Q4: 页面空白或黑屏

**原因**：
- TabBar 图标不存在（已修复）
- 云开发未初始化（已注释）
- 缓存问题

**解决**：
1. 清除缓存
2. 重新编译
3. 查看 Console 错误信息

### Q5: 商品列表没有数据

**原因**：使用模拟数据模式

**说明**：这是正常的，模拟数据中只有 5 个示例商品

**查看数据**：打开 `miniprogram/utils/mockData.js` 查看模拟数据
