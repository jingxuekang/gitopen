# 购物车页面实现说明

## 功能概述

购物车页面实现了完整的购物车管理功能，包括商品展示、选择、数量调整、删除和结算。

## 实现的功能

### 1. 商品列表展示
- 显示购物车中的所有商品
- 展示商品图片、名称、规格、价格、数量
- 标记库存不足的商品（显示"库存不足"标签，降低透明度）

### 2. 商品选择功能
- 单个商品选择/取消选择
- 全选/取消全选功能
- 实时更新选中商品数量

### 3. 数量调整
- 增加/减少商品数量
- 数量不能小于1
- 数量不能超过库存
- 实时验证库存并更新总价

### 4. 删除功能
- 单个商品删除（带二次确认）
- 批量删除选中商品（带二次确认）

### 5. 总价计算
- 实时计算选中商品的总价
- 只计算可用商品（库存充足）的价格
- 显示选中商品数量

### 6. 结算功能
- 检查是否有选中商品
- 检查选中商品是否都有库存
- 跳转到订单确认页面

### 7. 空购物车状态
- 显示空购物车提示
- 提供"去逛逛"按钮跳转到首页

## 技术实现

### 数据结构

```javascript
{
  items: [],           // 购物车商品列表
  totalPrice: 0,       // 总价（分）
  selectedCount: 0,    // 选中商品数量
  allSelected: false,  // 是否全选
  hasUnavailable: false // 是否有不可用商品被选中
}
```

### 云函数调用

- `getCart`: 获取购物车列表
- `updateCartItem`: 更新商品数量或选中状态
- `deleteCartItem`: 删除单个或批量删除商品

### 核心逻辑

#### 总价计算
```javascript
const totalPrice = items
  .filter(item => item.selected && item.available)
  .reduce((sum, item) => sum + item.subtotal, 0)
```

只计算选中且可用（库存充足）的商品。

#### 库存验证
- 添加商品时验证库存
- 增加数量时验证库存
- 显示库存不足标记
- 禁止库存不足商品结算

## UI设计

### 布局
- 顶部：商品列表（可滚动）
- 底部：固定操作栏（全选、删除、总价、结算）

### 样式特点
- 使用绿色主题色（#2C5F2D）
- 库存不足商品降低透明度
- 价格使用红色突出显示
- 按钮圆角设计

### 交互反馈
- 操作时显示加载提示
- 删除操作需要二次确认
- 操作成功显示Toast提示
- 库存不足时提示用户

## 验收标准

✅ 需求 5.3：显示购物车商品列表  
✅ 需求 5.6：标记库存不足商品  
✅ 需求 5.7：批量选择和删除  

## 注意事项

1. 所有金额使用"分"为单位
2. 每次显示页面时刷新购物车数据
3. 操作失败时重新加载购物车
4. 库存不足的商品不能结算
5. 删除操作需要用户确认
