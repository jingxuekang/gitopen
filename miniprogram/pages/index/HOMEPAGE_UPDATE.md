# 首页功能更新说明

## ✅ 新增功能

### 1. 排行榜功能
已添加完整的排行榜功能，包含三个榜单：

- **销量榜**：按商品销量排序，展示最热销的商品
- **好评榜**：按商品评分排序，展示评价最高的商品  
- **价格榜**：按商品价格升序排序，展示性价比最高的商品

### 2. 视觉风格优化
- 排行榜采用金色渐变背景，突出茶文化的高雅气质
- 前三名使用奖牌图标（🥇🥈🥉）
- 添加点击动画效果，提升交互体验
- 优化商品卡片阴影和悬浮效果

### 排行榜交互

1. **Tab切换**：点击不同Tab切换榜单类型
2. **自动加载**：切换Tab后自动加载对应排行数据
3. **点击跳转**：点击商品跳转到商品详情页
4. **排名显示**：
   - 前三名：显示奖牌图标
   - 其他名次：显示数字排名

### 排行榜数据

每个榜单显示前10名商品：

**销量榜**：
- 排序字段：`sales`
- 排序方向：降序（从高到低）
- 显示信息：销量数量

**好评榜**：
- 排序字段：`rating`
- 排序方向：降序（从高到低）
- 显示信息：评分

**价格榜**：
- 排序字段：`price`
- 排序方向：升序（从低到高）
- 显示信息："超值"标签

## 🚀 使用方法

### 1. 部署更新

**前端**：
- 前端代码已更新，无需额外操作

**后端**：
1. 右键 `cloudfunctions/getProducts` 文件夹
2. 选择"上传并部署：云端安装依赖"

### 2. 测试功能

1. 打开小程序首页
2. 滚动到"排行榜"区域
3. 点击不同Tab（销量榜/好评榜/价格榜）
4. 验证排行榜数据是否正确显示
5. 点击商品验证是否跳转到详情页

### 3. 数据要求

商品数据需要包含以下字段：

```json
{
  "name": "商品名称",
  "price": 29800,
  "sales": 100,      // 销量（必需）
  "rating": 4.8,     // 评分（必需）
  "images": ["..."],
  "status": 1
}
```
