# 商品详情页实现文档

## 功能概述

商品详情页是用户查看商品完整信息并做出购买决策的核心页面。

## 实现的功能

### 1. 商品图片轮播 (需求 4.1)
- 使用 `<swiper>` 组件实现图片轮播
- 支持左右滑动切换图片
- 显示轮播指示点
- 图片使用 `aspectFill` 模式保持比例

### 2. 商品信息展示 (需求 4.2)
- 显示商品价格（根据选中的SKU动态更新）
- 显示商品名称
- 显示销量和评分
- 显示当前库存（根据选中的SKU动态更新）
- 显示商品详细描述

### 3. 规格选择器 (需求 4.3)
- 弹窗形式的规格选择器
- 点击规格区域打开选择器
- 显示所有可用规格及其价格和库存
- 支持选择不同规格
- 已售罄的规格显示为禁用状态

### 4. 价格和库存更新 (需求 4.4)
- 选择规格后，页面价格自动更新为所选SKU的价格
- 库存信息同步更新为所选SKU的库存
- 实现了**属性 22：规格选择价格更新**

### 5. 评价列表 (需求 4.5)
- 显示最新5条用户评价
- 显示用户头像、昵称、评分和评价内容
- 提供"查看全部"按钮跳转到完整评价列表
- 评分使用星级显示

### 6. 收藏功能 (需求 4.6)
- 支持收藏/取消收藏商品
- 页面加载时检查收藏状态
- 收藏状态实时更新UI
- 创建了三个云函数：
  - `addFavorite`: 添加收藏
  - `removeFavorite`: 取消收藏
  - `getFavorites`: 获取收藏列表

### 7. 分享功能 (需求 4.6)
- 实现 `onShareAppMessage` 方法
- 分享标题为商品名称
- 分享图片为商品首图
- 分享路径包含商品ID，支持直接跳转

## 云函数

### getProductDetail
获取商品详情和评价信息

**输入参数：**
- `productId`: 商品ID

**返回数据：**
```javascript
{
  product: {
    _id, name, images, description, price, stock, sales, rating,
    skus: [{ skuCode, specValues, price, stock }]
  },
  reviews: [{ userId, rating, content, user: { nickname, avatar } }]
}
```

### addFavorite
添加商品到收藏列表

**输入参数：**
- `productId`: 商品ID

**功能：**
- 检查商品是否存在
- 检查是否已收藏（防重复）
- 添加收藏记录

### removeFavorite
从收藏列表移除商品

**输入参数：**
- `productId`: 商品ID

**功能：**
- 查找收藏记录
- 删除收藏记录

### getFavorites
获取用户的收藏列表

**返回数据：**
```javascript
[
  {
    _id, userId, productId, createdAt,
    product: { _id, name, images, price, ... }
  }
]
```

## 边界情况处理

1. **无SKU商品**：支持没有规格的商品，直接使用商品总价格和库存
2. **库存不足**：已售罄的SKU显示为禁用状态，无法选择
3. **加载失败**：显示友好的错误提示
4. **未选择规格**：购买或加购时提示用户选择规格
5. **收藏状态检查失败**：静默失败，不影响页面显示

## 用户体验优化

1. **加载状态**：显示"加载中..."提示
2. **操作反馈**：所有操作都有Toast提示
3. **视觉反馈**：选中的SKU高亮显示
4. **禁用状态**：售罄商品显示灰色禁用样式
5. **底部固定栏**：操作按钮固定在底部，方便点击

## 样式设计

- 使用卡片式布局，清晰分隔不同区块
- 价格使用红色突出显示
- 主色调为深绿色 (#2C5F2D)，符合茶叶主题
- 辅助色为金色 (#D4AF37)，用于次要按钮
- 响应式设计，使用rpx单位适配不同屏幕
