# 图片资源说明

## 目录结构

```
images/
├── tab/                    # 底部导航栏图标
│   ├── home.png           # 首页图标
│   ├── home-active.png    # 首页选中图标
│   ├── category.png       # 分类图标
│   ├── category-active.png # 分类选中图标
│   ├── cart.png           # 购物车图标
│   ├── cart-active.png    # 购物车选中图标
│   ├── user.png           # 我的图标
│   └── user-active.png    # 我的选中图标
├── banner/                 # 轮播图
├── category/               # 分类图标
│   ├── tea.png            # 茶叶图标
│   ├── chenpi.png         # 陈皮图标
│   └── teapot.png         # 紫砂壶图标
├── empty/                  # 空状态图片
│   ├── cart.png           # 购物车空状态
│   ├── order.png          # 订单空状态
│   ├── favorite.png       # 收藏空状态
│   └── search.png         # 搜索空状态
└── placeholder/            # 占位图
    └── product.png        # 商品占位图
```

## 图标规范

### 底部导航栏图标
- 尺寸：81px × 81px
- 格式：PNG
- 背景：透明
- 颜色：未选中 #999999，选中 #2C5F2D

### 分类图标
- 尺寸：120px × 120px
- 格式：PNG
- 背景：透明或白色

### 轮播图
- 尺寸：750px × 400px
- 格式：JPG/PNG
- 大小：< 200KB

### 空状态图片
- 尺寸：400px × 400px
- 格式：PNG
- 背景：透明

## 注意事项

1. 所有图片需要进行压缩优化
2. 使用 TinyPNG 或类似工具压缩图片
3. 图片命名使用小写字母和连字符
4. 避免使用中文命名
5. 建议使用 WebP 格式以获得更好的压缩率
