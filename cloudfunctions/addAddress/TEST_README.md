# 地址管理属性测试文档

## 测试概述

本测试文件验证地址管理功能的两个核心正确性属性：

### 属性 11：手机号格式验证
**验证需求：10.3**

*对于任意*收货地址，其手机号字段应该是恰好11位的数字字符串。

测试用例：
1. 任意字符串的手机号验证结果应该等于是否为11位数字
2. 有效手机号（11位数字）应该通过验证
3. 无效手机号（非11位或包含非数字字符）应该验证失败
4. 添加地址时，无效手机号应该被拒绝
5. 添加地址时，有效手机号应该通过验证

### 属性 12：地址数量限制
**验证需求：10.7**

*对于任意*用户，其收货地址数量应该不超过20个。

测试用例：
1. 当用户地址数量小于20时，应该允许添加新地址
2. 当用户地址数量达到20时，应该拒绝添加新地址
3. 地址数量限制应该在20个（边界测试）

### 综合属性测试

验证手机号和地址数量限制的组合：只有当手机号有效且地址数量未达上限时，才能成功添加地址。

## 运行测试

### 前置条件

确保已安装 Node.js 和 npm。

### 安装依赖

```bash
cd cloudfunctions/addAddress
npm install
```

### 运行测试

```bash
npm test
```

### 测试配置

- **属性测试库**：fast-check
- **单元测试库**：Jest
- **迭代次数**：每个属性测试运行100次

## 测试结果说明

所有测试应该通过，验证：

1. ✅ 手机号验证函数对任意输入都能正确判断是否为11位数字
2. ✅ 有效手机号（13000000000-19999999999）都能通过验证
3. ✅ 无效手机号（长度不对或包含非数字字符）都会被拒绝
4. ✅ 添加地址时会正确验证手机号格式
5. ✅ 地址数量小于20时可以添加新地址
6. ✅ 地址数量达到或超过20时会拒绝添加新地址
7. ✅ 边界情况（19、20、21个地址）都能正确处理
8. ✅ 手机号和地址数量限制的组合逻辑正确

## 测试覆盖的需求

- **需求 10.3**：手机号格式验证（11位数字）
- **需求 10.7**：地址数量限制（最多20个）

## 注意事项

1. 测试使用模拟的云函数环境，不需要实际的微信云开发环境
2. 测试验证的是核心业务逻辑，而非云函数的具体实现
3. 每个属性测试运行100次迭代，确保在各种随机输入下都能保持正确性
4. 测试包含边界情况和异常情况的验证
