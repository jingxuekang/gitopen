# 默认头像设置说明

## 需要的图片

在 `images/` 目录下需要一个默认头像图片：
- 文件名：`default-avatar.png`
- 尺寸：建议 200x200 像素或更大
- 格式：PNG（支持透明背景）

## 快速获取默认头像

### 方案1：使用占位图服务
可以从以下网站下载免费的默认头像：
- https://ui-avatars.com/api/?name=User&size=200&background=2C5F2D&color=fff
- https://avatar.vercel.sh/user.png

### 方案2：创建简单图标
使用任何图片编辑工具创建一个简单的用户图标：
1. 创建 200x200 的画布
2. 背景色：#2C5F2D（茶绿色）
3. 添加白色的用户图标或文字

### 方案3：临时方案
如果暂时没有图片，可以使用微信小程序的默认头像：
- 在代码中将路径改为空字符串 `''`
- 微信会自动显示默认头像

## 当前使用位置

默认头像在以下位置使用：
1. 用户中心页面 - 未登录状态
2. 用户中心页面 - 登录后未设置头像
3. 评论/评价列表 - 用户未设置头像时

## 注意事项

- 图片大小建议不超过 100KB
- 使用 PNG 格式以支持透明背景
- 确保图片清晰，适合在小尺寸下显示
